# greeter

A tiny Python project for trying konstant's factory (docs/LEVEL5.md section 7).

- `greeter.py`: `greet()` returns `hello world`.
- `test_greeter.py`: the project's one test (`python3 -m pytest -q`).

The goal in `goal.toml` asks for more: greet by name, a command line (`python3 greeter.py NAME`)
and this README kept. See the README of konstant, "Try the factory", for the steps. `goal.toml` is
the factory's input, not part of the project: copy the project without it.
